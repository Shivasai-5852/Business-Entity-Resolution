# Amazon ML Hackathon: Business Entity Resolution Challenge

## Project Overview
This repository contains the solution for the Amazon ML Hackathon: Business Entity Resolution Challenge. The objective is to build a highly accurate, robust, and scalable entity-matching system to resolve records representing the same real-world business entities across multiple data sources.

## Objective & Evaluation
- **Primary Goal**: Accurately match records from source datasets to resolve business entities.
- **Evaluation Metric**: F0.5 score, emphasizing precision while maintaining balanced recall.
